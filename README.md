# AI Chat Application

AI-powered chat application for Prompt Engineering & Vibe Coding.

## Features

- Google Gemini
- OpenRouter (OpenAI Compatible)
- Pollinations
- Multiple AI Roles
- Model Switching
- Dark / Light Theme
- Markdown Rendering
- Prompt Engineering Settings
- Responsive Design

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

Open index.html

## Environment

Create:

```
backend/.env
```

Example:

```env
PORT=3000
GEMINI_API_KEY=YOUR_KEY
OPENAI_API_KEY=YOUR_KEY
```
